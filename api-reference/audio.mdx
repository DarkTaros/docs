Bifrost's audio endpoints give you a unified interface for both directions of speech processing: text-to-speech (TTS) for generating audio from text, and speech-to-text (STT) for transcribing recorded audio into text. Both endpoints use the `provider/model` convention and return normalized responses, so you can swap from OpenAI's TTS to ElevenLabs without changing your integration beyond the model field.

## Provider Support

| Capability | Supported providers |
|---|---|
| **Text-to-Speech (TTS)** | `openai` (tts-1, tts-1-hd), `elevenlabs` |
| **Speech-to-Text (STT)** | `openai` (whisper-1), `groq` (whisper-large-v3) |

<Note>
  Provider support is actively expanding. If a provider you need is not listed, check the Bifrost changelog or raise a request on the GitHub repository.
</Note>

## Create Speech (Text-to-Speech)

Convert a text string into a spoken audio file.

```
POST http://your-host:8080/v1/audio/speech
```

The endpoint returns raw audio bytes with a content type that matches the requested format (e.g., `audio/mpeg` for MP3). You can stream the audio as it is generated by setting `stream_format` to `sse`.

### Request Parameters

<ParamField header="x-bf-vk" type="string">
  Your Bifrost virtual key. Alternatively, pass via `Authorization: Bearer`, `x-api-key`, or `x-goog-api-key`.
</ParamField>

<ParamField body="model" type="string" required>
  The TTS model in `provider/model` format.

  **Examples:**
  - `openai/tts-1`
  - `openai/tts-1-hd`
  - `elevenlabs/eleven_multilingual_v2`
</ParamField>

<ParamField body="input" type="string" required>
  The text you want to convert to speech. Maximum length varies by model (OpenAI supports up to 4,096 characters).
</ParamField>

<ParamField body="voice" type="string | array" required>
  The voice to use for synthesis. For OpenAI, choose from: `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`. For ElevenLabs, pass a voice ID string or a voice configuration object.
</ParamField>

<ParamField body="response_format" type="string" default="mp3">
  The audio format of the output file. Options: `mp3`, `opus`, `aac`, `flac`, `wav`, `pcm`.
</ParamField>

<ParamField body="speed" type="number" default="1.0">
  Playback speed multiplier between `0.25` and `4.0`. Only supported by OpenAI models.
</ParamField>

<ParamField body="stream_format" type="string">
  Set to `"sse"` to receive the audio as a Server-Sent Events stream. Useful for real-time playback scenarios where you want to start playing audio before the full file is ready.
</ParamField>

<ParamField body="instructions" type="string">
  Optional style or tone guidance for the voice (model support varies).
</ParamField>

<ParamField body="language_code" type="string">
  BCP-47 language code for multilingual models (e.g., `en-US`, `fr-FR`). Supported by ElevenLabs multilingual models.
</ParamField>

<ParamField body="fallbacks" type="array">
  Ordered list of fallback TTS models in `provider/model` format.
</ParamField>

### Example: Generate speech

<CodeGroup>

```bash cURL
curl http://your-host:8080/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "x-bf-vk: sk-bf-your-virtual-key" \
  -d '{
    "model": "openai/tts-1",
    "input": "Bifrost routes your AI requests to any provider through a single unified API.",
    "voice": "nova",
    "response_format": "mp3",
    "speed": 1.0
  }' \
  --output speech.mp3
```

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="http://your-host:8080/v1",
    api_key="sk-bf-your-virtual-key",
)

response = client.audio.speech.create(
    model="openai/tts-1",
    voice="nova",
    input="Bifrost routes your AI requests to any provider through a single unified API.",
    response_format="mp3",
)
response.stream_to_file("speech.mp3")
```

</CodeGroup>

The response is a binary audio file (`audio/mpeg` for MP3). Save the response body directly to a file.

### Example: Stream speech via SSE

```bash
curl http://your-host:8080/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "x-bf-vk: sk-bf-your-virtual-key" \
  --no-buffer \
  -d '{
    "model": "openai/tts-1",
    "input": "This audio is streamed back as server-sent events.",
    "voice": "alloy",
    "stream_format": "sse"
  }'
```

<Tip>
  Use `tts-1` for real-time applications where latency matters most, and `tts-1-hd` when audio quality is the priority. ElevenLabs models generally produce more natural-sounding output but have higher latency.
</Tip>

## Create Transcription (Speech-to-Text)

Transcribe an audio file into text.

```
POST http://your-host:8080/v1/audio/transcriptions
```

This endpoint accepts `multipart/form-data`. The audio file is passed in the `file` field. Supported formats include MP3, MP4, MPEG, MPGA, M4A, WAV, and WebM.

### Request Parameters

<ParamField header="x-bf-vk" type="string">
  Your Bifrost virtual key. Alternatively, pass via `Authorization: Bearer`, `x-api-key`, or `x-goog-api-key`.
</ParamField>

<ParamField body="model" type="string" required>
  The STT model in `provider/model` format.

  **Examples:**
  - `openai/whisper-1`
  - `groq/whisper-large-v3`
  - `groq/whisper-large-v3-turbo`
</ParamField>

<ParamField body="file" type="file" required>
  The audio file to transcribe. Maximum file size is 25 MB for OpenAI Whisper.
</ParamField>

<ParamField body="language" type="string">
  The language of the audio in ISO-639-1 format (e.g., `en`, `fr`, `de`). Providing this improves accuracy and speed. If omitted, Whisper auto-detects the language.
</ParamField>

<ParamField body="prompt" type="string">
  Optional text to guide the model's transcription style or provide context. Can improve accuracy for technical vocabulary or unusual names.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Output format. Options:
  - `json` — A JSON object with a `text` field (default)
  - `text` — Plain text
  - `srt` — SubRip subtitle format
  - `vtt` — WebVTT subtitle format
  - `verbose_json` — JSON with word-level timestamps and confidence scores
</ParamField>

<ParamField body="stream" type="boolean">
  When `true`, partial transcription results are streamed as they are generated.
</ParamField>

<ParamField body="fallbacks" type="array">
  Ordered list of fallback STT models in `provider/model` format.
</ParamField>

### Example: Transcribe an audio file

<CodeGroup>

```bash cURL
curl http://your-host:8080/v1/audio/transcriptions \
  -H "x-bf-vk: sk-bf-your-virtual-key" \
  -F "model=openai/whisper-1" \
  -F "file=@/path/to/recording.mp3" \
  -F "language=en" \
  -F "response_format=json"
```

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="http://your-host:8080/v1",
    api_key="sk-bf-your-virtual-key",
)

with open("recording.mp3", "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="openai/whisper-1",
        file=audio_file,
        language="en",
        response_format="json",
    )

print(transcript.text)
```

</CodeGroup>

## Response Fields (Transcription)

<ResponseField name="text" type="string">
  The full transcribed text.
</ResponseField>

<ResponseField name="language" type="string">
  The detected or specified language of the audio.
</ResponseField>

<ResponseField name="duration" type="number">
  Duration of the audio in seconds.
</ResponseField>

<ResponseField name="task" type="string">
  The task performed — always `"transcribe"` for this endpoint.
</ResponseField>

<ResponseField name="words" type="array">
  Word-level timestamps. Present only when `response_format` is `verbose_json`.

  <Expandable title="Word object fields">
    <ResponseField name="word" type="string">The transcribed word.</ResponseField>
    <ResponseField name="start" type="number">Start time in seconds.</ResponseField>
    <ResponseField name="end" type="number">End time in seconds.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="segments" type="array">
  Segment-level details including token IDs, log probabilities, and silence detection. Present only in `verbose_json` format.
</ResponseField>

<ResponseField name="usage" type="object">
  Token and duration usage for billing purposes.
</ResponseField>

## Error Responses

| Status | Meaning |
|---|---|
| `400` | Missing required field, unsupported file format, or file too large |
| `403` | Virtual key lacks permission for the requested audio provider |
| `500` | Upstream provider error |
