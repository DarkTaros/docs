Bifrost Enterprise is a strict superset of the open-source gateway. Every provider, integration, and SDK supported in the OSS edition works identically in Enterprise—same `config.json` schema, no re-integration required. On top of that foundation, Enterprise adds the reliability, security, and governance capabilities your organization needs to run AI workloads in production with confidence.

## What Enterprise adds

<CardGroup cols={2}>
  <Card title="Role-Based Access Control" icon="shield-halved" href="/enterprise/overview">
    Custom roles with fine-grained permissions across every Bifrost resource. Grant the Developer role full CRUD access to providers and keys, while the Viewer role sees read-only dashboards.
  </Card>
  <Card title="SSO & Identity Providers" icon="id-badge" href="/enterprise/overview">
    OIDC login and directory sync with Okta, Microsoft Entra ID, Keycloak, Zitadel, and Google Workspace. Users and groups stay in sync automatically.
  </Card>
  <Card title="Content Guardrails" icon="lock" href="/enterprise/guardrails">
    Real-time content safety using AWS Bedrock Guardrails, Azure Content Safety, Google Model Armor, CrowdStrike AIDR, GraySwan Cygnal, Patronus AI, Secrets Detection, and Custom Regex.
  </Card>
  <Card title="Audit Logs" icon="scroll" href="/enterprise/audit-logs">
    Immutable, HMAC-signed audit trails for every configuration change. Filterable by actor, resource, action, and date. Exportable as JSON, JSON Lines, or Syslog for SOC 2, HIPAA, GDPR, and ISO 27001.
  </Card>
  <Card title="Clustering & HA" icon="server" href="/enterprise/clustering">
    High-availability clustering with gossip-based state sync, automatic service discovery (Kubernetes, Consul, etcd, DNS, UDP, mDNS), and zero-downtime rolling deployments.
  </Card>
  <Card title="Datadog Connector" icon="chart-line" href="/enterprise/overview">
    Native Datadog APM, LLM Observability, and metrics integration with full per-request tracing—no custom instrumentation needed.
  </Card>
  <Card title="Log Exports" icon="database" href="/enterprise/overview">
    Automated export of request logs and telemetry to S3, GCS, BigQuery, and other data lakes on a configurable schedule.
  </Card>
  <Card title="Adaptive Load Balancing" icon="scale-balanced" href="/enterprise/overview">
    Predictive traffic routing with real-time provider health monitoring. Traffic shifts automatically to the fastest available upstream as conditions change.
  </Card>
  <Card title="Circuit Breaker" icon="bolt" href="/enterprise/overview">
    Automatic failover to a backup provider when a primary endpoint signals degradation via response headers, keeping your users unaware of upstream issues.
  </Card>
  <Card title="In-VPC Deployments" icon="building-shield" href="/enterprise/overview">
    Deploy entirely within your private cloud network. No AI request traffic ever crosses a public network boundary—ideal for regulated industries and air-gapped environments.
  </Card>
  <Card title="Access Profiles" icon="sliders" href="/enterprise/overview">
    Reusable provider, model, budget, and rate-limit policies that auto-allocate virtual keys to users at scale across teams and business units.
  </Card>
  <Card title="MCP Tool Groups" icon="toolbox" href="/enterprise/overview">
    Curated bundles of MCP tools that can be attached to virtual keys, teams, customers, users, providers, or API keys for fine-grained tool governance.
  </Card>
</CardGroup>

## Security & compliance

Bifrost Enterprise is designed for organizations with audit and regulatory requirements. Encryption at rest and in transit, vulnerability scanning, dependency management, and secure defaults ship out of the box. See the [deployment guides](/gateway/setup) for security hardening guidance specific to your environment.

## Deployment options

You can deploy Bifrost Enterprise on AWS (EKS/ECS with IRSA), GCP (GKE with Workload Identity), Azure (AKS with Workload Identity Federation), or on-premise in air-gapped environments. The [deployment guides](/gateway/setup) walk through each cloud provider in detail.
